


# Iris Flower Classification Using Machine Learning 🌸

## Overview
This project predicts the species of an Iris flower using four measurements: sepal length, sepal width, petal length, and petal width.

Developed as part of an internship learning project, it demonstrates a complete machine-learning workflow and an interactive Gradio application.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Gradio
- Joblib
- Google Colab

## Models Compared
- K-Nearest Neighbors (KNN)
- Decision Tree
- Support Vector Machine (SVM)

The models were evaluated using cross-validation and held-out test data. The final model was selected based on cross-validation accuracy.

## Features
- Data exploration and preparation
- Model training and comparison
- Classification metrics and confusion matrix
- Interactive Gradio interface
- Prediction of Iris species from user-entered measurements

## Dataset
The project uses the Iris dataset available through scikit-learn.

## How to Run
1. Open `iris_classification.ipynb` in Google Colab.
2. Run the notebook cells in order.
3. Install any required libraries if prompted.
4. Run the Gradio interface cell.
5. Enter flower measurements to get a prediction.
